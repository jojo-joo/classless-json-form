# Classless-json-form
minimun javascript library that generates and validates forms from [json-schema](https://json-schema.org).

## Features
- obey to json-schema [Draft 2020-12](https://json-schema.org/draft/2020-12)
- a minimum implementation of json-schema, see [detail]()
- the smallest footprint
- zero dependency
- support misc [classless style]()
